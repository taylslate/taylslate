# L2: pool anonymized priors from on-platform deals

Migration 067 is written and not applied. Nothing here was run against `ldtmhafewfifdizgfrnn`. Apply it after 066. 061 is reserved. 062, 063, and 064 are not in the repo.

## What shipped

`public.pooled_deal_priors` holds anonymized groups of booked on-platform deals. Booked means `show_signed`, `delivering`, `completed`, `signed`, or `live`, and `cancelled_at` is null. Category comes from `shows.categories` through `deals.show_id`. A group is `(category, placement, price_type)`. It is kept only when at least 5 distinct brands are in it. The brand key is `coalesce(brand_profile_id, brand_id)`. The table stores no brand, deal, show, booking, or user id.

`agreed_cpm` wins over `cpm_rate`. `agreed_placement` wins over `placement`. `agreed_episode_count` wins over `num_episodes`. Placement and price type are stored in the import-pool vocabulary (`mid-roll`, `flat`). `median_cpm` is set only for `cpm`.

`median_conversions_per_1k_downloads` uses `public.outcomes` when `booking_id`, `show_id`, `reported_impressions`, and `reported_conversions` all exist. The join is `booking_id = deals.id`. `show_id` must match the deal when it is set. A join on `show_id` alone is not used. Otherwise the value is `deal_conversion_reports.reported_conversions` over `guaranteed_downloads` times the coalesced episode count.

`refresh_pooled_import_priors()` is replaced in this file. An uploaded row enters only when the import is `confirmed`, `pooling_consent` is true, and `past_campaign_records.matched_show_id` is set. If that column does not exist, the function empties `pooled_import_priors` and inserts nothing. It does not reference the missing column.

`loadPooledPriors` reads both tables. A deal prior wins when the key exists in both. An import prior fills a key the deal pool does not have. A missing table leaves that source empty. Discovery already calls `loadPooledPriors`. `lib/discovery/tiered-universe.ts` is unchanged.

`GET /api/cron/pooled-priors` calls both refreshes. It returns 401 when `CRON_SECRET` is unset or the bearer token does not match. `vercel.json` gains one daily cron at 16:00 UTC. Regions are unchanged.

`/terms` shows the approved consent line:

Taylslate may use aggregated, anonymized data from deals booked and completed through Taylslate to improve pricing and recommendations. Aggregates never identify a brand, and each one combines at least five brands. Files you upload stay private unless you choose to share them.

## Throwaway grants

Migrations 001 through 067 were applied on a throwaway Postgres 16, with `auth.uid()`, `auth.users`, and `storage.objects` stubbed. `show_claims` and `outcomes` were stubbed so 020 can grant them. 067 was applied a second time. The hosted project was not used.

`information_schema.role_table_grants` for `public.pooled_deal_priors`, grantees `anon`, `authenticated`, `PUBLIC`, and `service_role`:

| grantee | privilege_type |
| --- | --- |
| service_role | DELETE |
| service_role | INSERT |
| service_role | SELECT |
| service_role | UPDATE |

`anon`, `authenticated`, and `PUBLIC` have no rows.

`information_schema.routine_privileges` for `refresh_pooled_deal_priors` and `refresh_pooled_import_priors`, same grantee filter:

| routine_name | grantee | privilege_type |
| --- | --- | --- |
| refresh_pooled_deal_priors | service_role | EXECUTE |
| refresh_pooled_import_priors | service_role | EXECUTE |

`anon`, `authenticated`, and `PUBLIC` have no execute. Anon and authenticated `SELECT`, `TRUNCATE`, and `EXECUTE` fail with permission denied.

Five booked brands in one category produce one row. Four brands produce none. A cancelled deal and a `brand_signed` or `planning` deal are ignored. A `show_signed` deal counts. Re-applying 067 leaves the same grants and the refresh still returns the two groups from the fixture.

## Known gaps

- 067 is not applied. Do not run the refresh on the hosted project until Chris says so.
- `/terms` is behind the login gate. `proxy.ts` is outside this job, and the app is login-only. A signed-out request to `/terms` redirects to `/login`.
- The marketing footer Terms link still points at `#`. `components/marketing/marketing-chrome.tsx` is outside this job.
- Deal priors and import priors are not added together. A brand who both booked a deal and uploaded a file would be counted twice if the brand counts were summed, and the pool does not store brand ids. Each source keeps its own 5-brand bar. The deal row wins when the key matches.
- The executable check uses throwaway Postgres, the same harness as 060, 065, and 066. It is skipped when Postgres binaries are absent. `@electric-sql/pglite` was not added. `package.json` is outside this job.
